# Strings e Textos em JavaScript

## Conceitos abordados

- Declaração de strings (aspas simples, duplas e template strings)
- Propriedade `.length`
- Acesso a caracteres (`[]` e `.charAt()`)
- Concatenação
- Imutabilidade das strings
- Métodos essenciais:
  - `toUpperCase()` / `toLowerCase()`
  - `trim()` / `trimEnd`
  - `includes()`, `startsWith()`, `endsWith()`
  - `indexOf()` / `lastIndexOf()`
  - `slice()`, `substring()`, `substr()`
  - `replace()` / `replaceAll()`
  - `split()` e `join()`
  - `repeat()`
  - `padStart()` / `padEnd()`
